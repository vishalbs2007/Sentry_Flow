## What Changed

Implemented live network traffic capture capability that captures packets from network interfaces and saves them as PCAP files for subsequent flow extraction and classification.

**Plain-language summary:**
Created a module that can capture real network traffic directly from your network adapter (like Ethernet or Wi-Fi), similar to how Wireshark works. This allows FlowSentry to analyze live traffic in addition to pre-recorded PCAP files.

## Implementation Details

### Core Features

1. **Live Packet Capture:**
   - Captures from specified network interface
   - Configurable packet count or duration
   - Berkeley Packet Filter (BPF) support for selective capture
   - Automatic interface detection

2. **Interface Management:**
   - List available interfaces
   - Auto-detect default interface
   - Cross-platform support (via Scapy)

3. **Capture Modes:**
   - **Count-based:** Capture N packets
   - **Time-based:** Capture for N seconds
   - **Filter-based:** Capture only matching traffic (e.g., "tcp port 80")

4. **CLI Interface:**
   ```powershell
   # Capture 1000 packets
   python -m capture.live_capture --output capture.pcap --count 1000
   
   # Capture for 60 seconds
   python -m capture.live_capture --output capture.pcap --timeout 60
   
   # Capture HTTP traffic only
   python -m capture.live_capture --output capture.pcap --filter "tcp port 80"
   
   # List interfaces
   python -m capture.live_capture --list-interfaces
   ```

### Error Handling

- **Missing Npcap:** Clear error message with download link
- **Permission denied:** Explains need for Administrator privileges
- **No interface:** Graceful fallback to default or error
- **Keyboard interrupt:** Clean shutdown on Ctrl+C

   - Acceptable for demo and moderate traffic

## Technical Notes

### Scapy Capture API

```python
from scapy.all import sniff

packets = sniff(
    iface="Ethernet",      # Network interface
    count=1000,            # Number of packets
    timeout=60,            # Timeout in seconds
    filter="tcp port 80",  # BPF filter
    prn=lambda x: x.summary()  # Per-packet callback
)
```

### BPF Filter Examples

- **HTTP:** `tcp port 80`
- **HTTPS:** `tcp port 443`
- **DNS:** `udp port 53`
- **All TCP:** `tcp`
- **Specific host:** `host 192.168.1.1`
- **Network:** `net 192.168.0.0/24`
