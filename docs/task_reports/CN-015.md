#### 2. Schema Parity Validation

**Validation Logic:**
```python
def _validate_schema(self, features: pd.DataFrame):
    expected_features = self.model_metadata['selected_features']
    actual_features = set(features.columns)
    
    missing = set(expected_features) - actual_features
    if missing:
        raise SchemaMismatchError(f"Missing features: {missing}")
```

**Ensures:**
- Features from PCAP match training features
- No silent failures from schema mismatch
- Clear error messages for debugging

**Error Example:**
```
❌ Schema mismatch: 
Schema validation failed: 3 required features missing.
Missing features: ['flow_iat_max', 'fwd_packets_total', 'bwd_bytes_mean']
Expected: 9 features
Got: 6 features

💡 Hint: Model may have been trained with different features.
```

### Example 5: Programmatic Usage

```python
from inference.pcap_classifier import PcapClassifier
from pathlib import Path

# Initialize classifier
classifier = PcapClassifier(model_id=None)  # Use active model

# Classify PCAP
predictions, summary = classifier.classify_pcap(
    pcap_path=Path("simulation/pcaps/test.pcap"),
    output_dir=Path("artifacts/predictions/test"),
    include_confidence=True
)

# Access results
print(f"Classified {summary['flow_count']} flows")
print(f"Average confidence: {summary['average_confidence']:.4f}")

# Flows per class
for cls, count in summary['flows_per_class'].items():
    print(f"{cls}: {count} flows")

# Per-flow predictions
for idx, row in predictions.iterrows():
    print(f"{row['src_ip']} → {row['dst_ip']}: {row['predicted_class']} ({row['confidence']:.4f})")
```
