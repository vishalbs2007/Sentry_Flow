## Tests Implemented

### Integration Tests (7 tests)

1. **test_dataset_to_preprocessing_integration**
   - Tests: Dataset loading → Preprocessing pipeline
   - Verifies: Transformer fit/transform, imputation, scaling

2. **test_preprocessing_to_training_integration**
   - Tests: Preprocessing → Model training
   - Verifies: Pipeline construction, cross-validation execution

3. **test_training_to_evaluation_integration**
   - Tests: Model training → Evaluation
   - Verifies: Pipeline save/load, prediction, metrics computation

4. **test_evaluation_to_registry_integration**
   - Tests: Evaluation → Model registry
   - Verifies: Model registration, artifact storage, metadata

5. **test_leakage_guard_train_test_disjoint**
   - Tests: Train/test set disjointness (leakage guard)
   - Verifies: No row overlap between train and test sets
   - Marker: `requires_dataset` (runs on real data)

6. **test_leakage_guard_models_cannot_import_test_loader**
   - Tests: Structural leakage guard
   - Verifies: models/ cannot access test_loader

7. **test_registry_to_predictor_integration**
   - Tests: Model registry → Predictor pipeline
   - Verifies: Model loading, prediction on new data
