## Root Cause

**Scapy Requirement:** Scapy's `AsyncSniffer` with `offline=input_file` calls `tcpdump()` internally to read PCAP files. tcpdump is provided by Npcap/WinPcap.

**Error:**
```
scapy.error.ScapyException: tcpdump is not available
  File "scapy\sendrecv.py", line 1223
    (_offline_pcap_reader(fname, flt, quiet), fname)
  File "scapy\sendrecv.py", line 1071
    proc = tcpdump(source, args=["-w", "-"], flt=flt, getproc=True, quiet=quiet)
```

## Solution

### Install Npcap (Required)

1. Download: https://npcap.com/#download
2. Run installer as Administrator
3. Select "Install Npcap in WinPcap API-compatible mode"
4. Enable "Support loopback traffic (advanced)" if needed
5. Restart computer
