### Limitations Documented

#### 1. Blocked Features (Technical Dependencies)

**PCAP Pipeline (CN-013-015):**

- **External Tool:** CICFlowMeter (Java-based, multiple implementations)
- **Verification Gate:** G-CFM (CICFlowMeter command must be verified before use)
- **Documented:** `docs/task_reports/CN-013.md` (not attempted due to dependency)

**Impact:** Cannot process new PCAP files, cannot classify captured traffic

**Mitigation:** ISCX-VPN2016 dataset provides pre-extracted flow CSVs (79 features already computed)

---

#### 2. Known Issues (E2E Testing - CN-020)

**Issue 1: Demo Script Unicode Error (Windows)**
- **Symptom:** `UnicodeEncodeError: 'charmap' codec can't encode character '\u2705'`
- **Cause:** `scripts/demo.py` uses emoji, Windows PowerShell default encoding (cp1252)
- **Workaround:** `$env:PYTHONIOENCODING = "utf-8"` before running
- **Impact:** Low (demo script is presentation tool, not core functionality)
- **Documented:** README.md Quick Start, DEMO.md Pre-Flight Checklist, CN-020 report

**Issue 2: Old Model Feature Mismatch**
- **Symptom:** `ValueError: Feature names should match... Unnamed: 0 missing`
- **Cause:** Models trained before preprocessing fix (2026-10-14 01:22) have incompatible schema
- **Resolution:** Use recent models only (all 4 evaluated models work correctly)
- **Impact:** None (best model XGBoost is recent, evaluates successfully)
- **Documented:** CN-020 report, FINAL_REPORT_INPUTS artifact provenance

---

#### 3. Model-Specific Limitations

**SVM Scalability (CN-008):**
- **Issue:** SVM training O(n²) time complexity
- **Decision:** Train on 42% stratified subsample (20,032 / 47,696 samples)
- **Result:** Poor performance (70.10% accuracy, 65.37% macro F1)
- **Documented:** RID-06 (subsample policy), CN-008 report, comparison report

**Rationale:** Full SVM training would take ~40 minutes, still slower than other models. Three other models work well (Decision Tree, Random Forest, XGBoost).

---

#### 4. Dataset Limitations

**Dataset Specificity:**
- Results specific to ISCX-VPN2016 (Canadian university network)
- Different traffic patterns may need retraining
- Generalization to other networks requires validation

**Class Imbalance:**
- Streaming: 4.6% of training data (smallest class)
- May have lower performance (93.9% F1 vs. 99.5% VoIP)
- Mitigation: Stratified split, macro-F1 scoring

**Four Classes Only:**
- Limited to Web, VoIP, Streaming, File Transfer
- Real networks have more types (gaming, IoT, P2P, video calls)
- Extension requires labeled dataset with additional classes
