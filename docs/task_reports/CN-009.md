## Feature Importance Analysis (XGBoost)

XGBoost provides three types of feature importance:
1. **Gain** (default): Average gain/improvement when feature is used
2. **Weight**: Frequency of feature usage for splitting
3. **Cover**: Average coverage (samples affected) by feature

## Analysis: XGBoost vs Random Forest

### Similarities:
- Both tree-based ensembles
- Both achieve >94% CV F1
- Both select same 9 features
- Both prioritize timing features

### Differences:

| Aspect | Random Forest | XGBoost |
|--------|---------------|---------|
| **Ensemble Type** | Parallel (bagging) | Sequential (boosting) |
| **CV F1** | 94.04% | 96.29% (+2.25 pts) |
| **Training** | 1.6 min | 2 min |
| **Top Feature** | duration (14.26%) | mean_fiat (16.54%) |
| **Learning** | Independent trees | Learn from errors |
| **Overfitting Risk** | Lower (averaging) | Higher (boosting) |

**XGBoost Advantages:**
- Better CV performance (+2.25%)
- Learns complex patterns through boosting
- Regularization controls overfitting

**Random Forest Advantages:**
- Slightly faster training
- More robust (less sensitive to hyperparameters)
- Lower overfitting risk

**Verdict:** Both excellent. Test set evaluation (CN-010) will determine final winner.
