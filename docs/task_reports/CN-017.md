## Implementation Details

### Core Features

1. **Continuous Monitoring:**
   - Captures traffic in time windows (default: 10 seconds)
   - Classifies flows immediately after each window
   - Displays results with class distribution
   - Tracks cumulative statistics

2. **Window-Based Processing:**
   - Each window: Capture → Extract → Classify → Display
   - Configurable window duration
   - Automatic PCAP file management
   - Optional PCAP retention for analysis

3. **Live Display:**
   - Per-window flow counts and class distribution
   - Confidence scores
   - Sample flows with IP addresses
   - Visual bar charts (ASCII)
   - Session-wide statistics

4. **Graceful Shutdown:**
   - Ctrl+C to stop monitoring
   - Displays session summary
   - All captured files retained

### CLI Interface

```powershell
# Basic real-time monitoring
python -m inference.realtime_classifier

# Custom window duration
python -m inference.realtime_classifier --window 5

# Filter specific traffic
python -m inference.realtime_classifier --filter "tcp"

# Save to custom directory
python -m inference.realtime_classifier --output artifacts/monitoring
```

## Decisions Touched

**Design Decisions:**
- **Window-based approach:** Balances responsiveness vs. computational cost
  - 10-second windows provide near-real-time feedback
  - Allows meaningful flow aggregation
- **Terminal display:** Simple, accessible, works everywhere
  - Future: Could add web-based dashboard
- **PCAP retention:** Save all capture files by default
  - Allows post-analysis
  - Can be disabled to save disk space

   - Limited to text output
   - Future: Web dashboard

4. **Flow Aggregation:**
   - Flows may span multiple windows
   - Each window analyzed independently
   - Future: Session tracking across windows
