### 3. UTF-8 Encoding Workaround

**Issue:** `scripts/demo.py` uses emoji characters (✓, ✗, ⚠️)  
**Cause:** Windows PowerShell default encoding (cp1252) doesn't support emoji  
**Solution:** Set `$env:PYTHONIOENCODING = "utf-8"` before running

**Documented In:**
- `docs/DEMO.md` — Pre-flight checklist
- `docs/demo_fallbacks.md` — Known Issues section
- `docs/task_reports/CN-020.md` — E2E test known issues

**Decision:** Workaround sufficient (demo script is presentation tool, not core functionality)
