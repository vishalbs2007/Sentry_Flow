## Known Issues

### Issue 1: Demo Script Unicode Error (Windows)

**Test:** `test_scenario_a_demo_script`

**Symptom:**
```
UnicodeEncodeError: 'charmap' codec can't encode character '\u2705' in position X: 
character maps to <undefined>
```

**Root Cause:**
- `scripts/demo.py` uses emoji characters (✓, ✗, ⚠️) in output
- Windows PowerShell terminal uses `cp1252` encoding by default
- Emoji characters not supported in `cp1252` codepage

**Impact:**
- Demo script fails on Windows systems with default terminal encoding
- Does not affect core functionality (evaluation, comparison, registry)
- Only affects presentation/demo script

**Workaround:**
```powershell
# Set UTF-8 encoding before running
$env:PYTHONIOENCODING = "utf-8"
python scripts/demo.py
```

**Recommendation:**
- Document workaround in README.md
- OR: Update demo.py to detect terminal encoding and use ASCII fallback
- OR: Use ASCII-safe characters (*, +, !) instead of emoji

**Decision:** Document workaround (low priority - demo script is not core functionality).

### Issue 2: Old Model Feature Mismatch

**Test:** `test_scenario_b_model_evaluation`

**Symptom:**
```
ValueError: Feature names should match those that were passed during fit.
Feature names unseen at fit time:
- Unnamed: 0
```

**Root Cause:**
- Old models (e.g., `decision_tree_20261014_010406`) were trained on dataset with `Unnamed: 0` column
- Current `preprocessing/test_loader.py` drops `Unnamed: 0` column (correct behavior)
- Evaluating old models with current data loader causes feature name mismatch

**Impact:**
- Cannot evaluate models trained before preprocessing fix
- Does not affect new models (all models trained after fix work correctly)
- XGBoost best model (`xgboost_20261014_012230`) evaluates successfully

**Resolution:**
- Old models are deprecated, evaluation not needed
- All recent models (Decision Tree, XGBoost, Random Forest, SVM) trained correctly
- Best model (XGBoost) selected from correctly-trained models

**Recommendation:**
- Document that models trained before 2026-10-14 01:22 are deprecated
- Remove old models from registry if present
- No code changes needed (preprocessing is now correct)

**Decision:** Document deprecation (no action needed - old models not used).
