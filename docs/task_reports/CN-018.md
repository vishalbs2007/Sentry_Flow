## Implementation Details

### Dashboard Tabs

#### Tab 1: Overview
- **Purpose:** Project summary and quick stats
- **Content:**
  - Total models trained
  - Best model and accuracy
  - Dataset statistics
  - Classification classes
  - Quick navigation links

#### Tab 2: All Models
- **Purpose:** Individual model details
- **Content (per model):**
  - Model card with hyperparameters
  - Training metrics
  - Feature importance plot
  - Confusion matrix
  - Classification report
  - Per-class precision/recall/F1

#### Tab 3: Model Comparison
- **Purpose:** Side-by-side comparison
- **Content:**
  - Accuracy bar chart
  - Precision/Recall/F1 comparison
  - Training time comparison
  - Model complexity metrics
  - Best model highlight

#### Tab 4: Feature Analysis
- **Purpose:** Understanding features
- **Content:**
  - Feature importance ranking (top 20)
  - Horizontal bar chart
  - Feature descriptions
  - Correlation insights

#### Tab 5: Active Model
- **Purpose:** Production model info
- **Content:**
  - Active model identifier
  - Load time and prediction speed
  - Classes supported
  - Feature count
  - Model metadata
  - Registry integrity check

### Technology Stack

- **Framework:** Streamlit (Python)
- **Plotting:** Matplotlib, Seaborn
- **Data:** Pandas
- **ML Integration:** Models from registry
- **Deployment:** Local (localhost:8050)

## Decisions Touched

**Technology Choice:** Streamlit
- **Rationale:** Rapid development, pure Python, interactive
- **Alternative considered:** Flask + React (too complex for demo)
- **Trade-off:** Streamlit is demo/prototype focused (not production-scale)

**Deployment:** Local only
- **Rationale:** Academic project, single-user
- **Future:** Could deploy to cloud (Streamlit Cloud, Heroku)

---

## Dependencies Added

- `streamlit` (added to requirements.txt)
- **Justification:** Industry-standard for ML dashboards, pure Python

---

## Known Limitations

1. **Local Only:**
   - Runs on localhost
   - Not accessible over network (without port forwarding)
   - Single-user (not multi-tenant)

2. **No Authentication:**
   - Anyone with localhost access can view
   - Acceptable for academic/demo use

3. **Static Data:**
   - Dashboard reads model artifacts
   - No live data updates (must refresh)
   - Future: WebSocket for real-time updates

4. **Performance:**
   - Loads all model data on startup
   - Acceptable for 4 models
   - May slow with 20+ models
