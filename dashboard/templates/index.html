🛡️ FlowSentry

ML-Based Network Traffic Classification

📊 Flow-Level Statistical Features 🔒 No Payload Inspection 🤖 4 ML Models

📊 Project Overview

🎯 Goal

Classify network traffic by flow behavior (timing, volume, patterns) WITHOUT inspecting packet payloads.

🔬 Approach

  • Extract flow-level statistical features
  • Train ML models on labeled dataset (ISCX-VPN2016)
  • Classify into 4 categories: Web Browsing, VoIP, Streaming, File Transfer

📚 Models

  • Decision Tree: Interpretable baseline
  • Random Forest: Ensemble of trees
  • SVM: Kernel method
  • XGBoost: Gradient boosting

🌐 Network Topology & Packet Tracer

🏗️ Cisco Packet Tracer Topology

The FlowSentry project includes a comprehensive Cisco Packet Tracer simulation demonstrating all four traffic classes in a realistic network environment.

📡 Network Architecture

Router: Cisco 2911
Gateway between client and server networks
Switch: Cisco 2960-24TT
Layer 2 switching for client connections
Clients: 4 PCs (10.0.0.10-13)
Traffic generators for each class
Servers: 4 Servers (10.0.1.100-103)
HTTP, SIP, RTSP, FTP services

🔄 Traffic Classes Simulated

Class Service Port Duration Key Characteristics
🌐 Web Browsing HTTP 80 10-15s Bursty, request-response pattern
📞 VoIP SIP/RTP 5060/RTP 20-30s Constant rate, small packets, low latency
🎬 Streaming RTSP 554 30-45s Sustained throughput, buffer-based
📁 File Transfer FTP 21 15-20s Bulk transfer, TCP window-based

🚀 Quick Start Guide

  1. Open docs/packet_tracer_guide.md for detailed instructions
  2. Open Cisco Packet Tracer and build the topology
  3. Configure services on all servers (HTTP, SIP, RTSP, FTP)
  4. Generate traffic from clients to servers
  5. Export PCAPs using Simulation Mode
  6. Classify with FlowSentry: python -m inference.classify --pcap traffic.pcap
